Données collectées

Ce site collecte uniquement les données que vous soumettez volontairement via le formulaire de contact :

  • Nom et prénom
  • Adresse e-mail
  • Numéro de téléphone (optionnel)
  • Message libre

Ces données sont transmises via le service Formspree (formspree.io) et sont utilisées exclusivement pour répondre à votre demande.

Base légale du traitement

Le traitement est fondé sur votre consentement explicite (article 6.1.a du RGPD), exprimé par la case à cocher obligatoire du formulaire de contact.

Durée de conservation

Vos données sont conservées le temps nécessaire au traitement de votre demande et au maximum 3 ans à compter du dernier contact.

Partage des données

Vos données ne sont jamais vendues ni cédées à des tiers. Elles transitent par Formspree pour des raisons techniques — consultez la politique de confidentialité de Formspree.

Cookies et traceurs

Ce site n'utilise aucun cookie de traçage, aucun outil d'analyse (Google Analytics ou autre), aucun pixel de retargeting. Aucune donnée de navigation n'est collectée.

Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit d'opposition : vous opposer au traitement
  • Droit à la portabilité : recevoir vos données dans un format structuré

Pour exercer ces droits, contactez-moi via le formulaire de contact.

Vous avez également le droit d'introduire une réclamation auprès de l' Autorité de protection des données (APD), rue de la Presse 35, 1000 Bruxelles.

Hébergement

Ce site est hébergé sur GitHub Pages (GitHub, Inc., États-Unis). GitHub peut collecter des données techniques (adresses IP) à des fins de sécurité. Consultez la politique de confidentialité de GitHub.
